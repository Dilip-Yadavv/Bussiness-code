# ⚡ Apex Architectural Metalworks — Bespoke Fabrication Atelier Portal

A world-class, architectural-grade website and live engineering estimation studio for custom iron grills, high-security doors, driveway gates, and metal facades.

---

## 🌟 Real-World Luxury Architectural Features

1. **📐 2D Live Vector Blueprint Visualizer & Cost Engine**:
   - Live architectural SVG CAD canvas that **dynamically redraws** as the user changes dimensions, opening counts, and bar geometry (*Modern Vertical*, *Diamond Lattice*, *Victorian Belly Curve*, or *Parametric CNC Moroccan Honeycomb*).
   - Real-feel metallic protective swatches (*Matte Jet Black 7-Tank Powder Coat*, *Burnished Antique Bronze*, *Satin Brushed Stainless SS-304*, and *PVD Titanium Gold*).
   - Instant calculation of **Total Area (Sq. Ft)**, **Alloy Mass (~Kg)**, and **Price Breakdown (₹)** with **1-Click Blueprint Transmission to WhatsApp**.

2. **↔️ Interactive Before & After Transformation Slider**:
   - Interactive draggable comparison showing old weathered/rusted window frames transformed into luxury 7-tank zinc powder-coated grills.

3. **🏗️ Real Project Case Studies**:
   - Real architectural installations (*Villa Solaria*, *Skyline High-Rise*) featuring alloy specs, square footage, turnaround timelines, and architect endorsements.

4. **🧪 Engineering Standards & Material Tolerances Table**:
   - Displays real engineering metrics: **Tensile Strength (MPa)**, **Anti-Burglary Security Ratings**, **Mass per Sq.Ft**, and base pricing.

5. **🚨 Emergency Repair & Burglary Hardening Hotline Bar**:
   - Quick-action contact bar for urgent broken hinges, gate track repairs, and emergency welding.

6. **🤖 Gemini AI Architectural Advisor (24/7)**:
   - Floating chat assistant with instant question chips for balcony child safety, steel gauge selection (10G/12G/14G/16G), and anti-rust zinc phosphating advice.
   - Dual mode: Works 100% offline with zero setup, plus supports optional Google Gemini 1.5 Flash API Key integration in Admin.

7. **⚙️ Self-Management Studio Admin Panel (PIN: `1234`)**:
   - Update Atelier profile details, phone numbers, and WhatsApp links.
   - Rate Master for ₹/sq.ft and metal mass updates.
   - Portfolio inventory manager to add/remove projects.
   - Quotation and site measurement leads tracker.
   - JSON Backup & Export.
